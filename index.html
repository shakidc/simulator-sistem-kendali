Panduan Penggunaan

Selamat datang di Virtual Lab Sistem Kendali Motor Listrik DC. Virtual Lab ini memfasilitasi pemahaman mendalam mengenai dinamika Speed Control (Pengaturan Kecepatan) dan Position Control (Servomechanism) pada aktuator elektrik.

Skenario Eksperimen Terstruktur:

1. Identifikasi Karakteristik Open-Loop (Plant Analysis)

  • Tujuan: Memahami respon alami motor tanpa kendali.
  • Langkah: Matikan mode PID. Variasikan $V_{in}$. Amati respon kecepatan.
  • Analisis: Perhatikan konstanta waktu ($\tau$). Motor dengan inersia ($J$) besar akan membutuhkan waktu lebih lama untuk mencapai kecepatan stabil (steady-state). Hitung $\tau$ secara grafis (waktu saat mencapai 63.2% nilai akhir).

2. Kendali Kecepatan (Speed Regulation)

  • Konteks: Aplikasi seperti Conveyor Belt atau Kipas Angin.
  • Tantangan: Mempertahankan kecepatan konstan meski ada gangguan.
  • Tips Tuning:
    • Mulai dengan kontroler PI ($K_d=0$).
    • $K_p$ menentukan seberapa cepat sistem bereaksi.
    • $K_i$ mutlak diperlukan untuk menghilangkan Steady State Error akibat gesekan ($b$). Hati-hati, $K_i$ berlebih menyebabkan osilasi.

3. Kendali Posisi Sudut (Servo Position Control)

  • Konteks: Robot Arm, CNC Machine, atau Antenna Tracker.
  • Dinamika Unik: Sistem posisi memiliki integrator alami ($\theta = \int \omega dt$). Ini membuat sistem secara alami lebih tidak stabil dibandingkan sistem kecepatan.
  • Tips Tuning:
    • Kontroler PD seringkali lebih efektif daripada PI.
    • $K_p$ bertindak seperti "kekakuan pegas" (spring stiffness) virtual. Semakin besar, semakin kuat motor menuju target, namun semakin memantul (overshoot).
    • $K_d$ bertindak sebagai "peredam kejut" (shock absorber). Gunakan $K_d$ untuk meredam overshoot yang disebabkan oleh $K_p$.
    • Gunakan $K_i$ kecil hanya jika posisi akhir tidak tercapai secara presisi (contoh: ada beban gravitasi).

Model Matematis Motor DC

Motor DC armature-controlled adalah sistem elektromekanis yang menghubungkan domain elektrik (Tegangan/Arus) dan mekanik (Torsi/Kecepatan).

1. Penurunan Model Fisik

Persamaan Elektrik (Kirchhoff): $$ V(t) = R_a i(t) + L_a \frac{di(t)}{dt} + K_b \omega(t) $$
Persamaan Mekanik (Newton): $$ K_t i(t) = J \frac{d\omega(t)}{dt} + b \omega(t) $$

2. Fungsi Alih Kecepatan (Speed TF)

Output adalah kecepatan sudut $\omega(s)$. Sistem umumnya mendekati Orde-2 (atau Orde-1 jika $L_a \approx 0$)

$$ G_{\omega}(s) = \frac{\omega(s)}{V(s)} = \frac{K_t}{(L_a s + R_a)(J s + b) + K_t K_b} $$

Secara praktis, ini adalah sistem Type 0, artinya input step tegangan menghasilkan output kecepatan konstan.

3. Fungsi Alih Posisi (Position TF)

Output adalah sudut $\theta(s)$. Karena $\omega(t) = d\theta(t)/dt$, maka dalam domain Laplace $\omega(s) = s\theta(s)$ atau $\theta(s) = \frac{1}{s}\omega(s)$

$$ G_{\theta}(s) = \frac{\theta(s)}{V(s)} = \frac{1}{s} G_{\omega}(s) = \frac{K_t}{s[(L_a s + R_a)(J s + b) + K_t K_b]} $$

Ini menjadikan sistem kendali posisi sebagai sistem Orde-3 (atau Orde-2 jika $L_a$ diabaikan) dan merupakan sistem Type 1 (memiliki kutub di titik asal $s=0$).

4. Penjelasan Parameter Fisis

Simbol Nama Parameter Pengaruh pada Sistem
$R_a$ Resistansi Jangkar Menghambat arus. Nilai besar mengurangi arus start dan torsi maksimal, memperlambat respon.
$L_a$ Induktansi Jangkar Menghambat perubahan arus. Nilai besar memperlambat respon arus (electrical time constant).
$K_t$ Konstanta Torsi Mengubah arus listrik menjadi torsi mekanik. Nilai besar membuat motor lebih bertenaga.
$K_b$ Konstanta GGL Lawan Redaman elektrik. Menghasilkan tegangan lawan saat berputar, membatasi kecepatan maksimum.
$J$ Momen Inersia Kelembaman massa. Nilai besar membuat motor lambat berakselerasi (respon transien lambat).
$b$ Gesekan Viscous Gesekan pada poros. Mengurangi kecepatan steady-state dan membantu meredam osilasi.

5. Diagram Blok Sistem Kalang Tertutup

Insight Penting: Penambahan integrator $1/s$ pada sistem posisi menambah pergeseran fase (phase lag) sebesar -90°. Inilah alasan mengapa sistem posisi lebih sulit distabilkan dan sering membutuhkan aksi Derivatif ($D$) untuk memberikan "phase lead".

Analisis Kestabilan & Root Locus

Kestabilan sistem ditentukan oleh lokasi akar-akar persamaan karakteristik (poles) pada bidang kompleks S.

1. Sistem Kecepatan (Orde 2 Dominan)

Fungsi alih loop tertutup memiliki karakteristik standar sistem orde dua:

$$ s^2 + 2\zeta\omega_n s + \omega_n^2 = 0 $$
  • Underdamped ($0 < \zeta < 1$): Terjadi jika $K_p$ terlalu besar relatif terhadap gesekan $b$. Respon cepat tapi berosilasi.
  • Overdamped ($\zeta > 1$): Terjadi jika penguatan rendah atau gesekan tinggi. Respon lamban (sluggish).

2. Sistem Posisi (Efek Integrator)

Pada kendali posisi, kita mengendalikan integral dari kecepatan. Tanpa kontroler PID (hanya P), Root Locus sistem posisi dimulai dari pole di origin ($s=0$) dan pole mekanik/elektrik.

  • Saat Gain ($K_p$) dinaikkan, pole-pole sistem bergerak menjauhi sumbu real dan mendekati sumbu imajiner.
  • Ini berarti: Semakin tinggi $K_p$ pada kendali posisi, sistem akan semakin osilatif. Berbeda dengan kendali kecepatan dimana gesekan ($b$) seringkali cukup untuk meredam, pada kendali posisi kita seringkali wajib menambahkan redaman buatan melalui term Derivatif ($K_d$).

3. Kriteria Kestabilan Praktis

Untuk desain yang aman di dunia nyata:

  • Phase Margin: Usahakan > 45° untuk mencegah osilasi berlebihan saat parameter berubah (robustness).
  • Gain Margin: Diperlukan agar sistem tetap stabil meskipun komponen menua atau gain amplifier berubah.

Kendali PID Realistis: Teori & Praktik

Dalam implementasi nyata, algoritma PID $u(t) = K_p e(t) + K_i \int e dt + K_d \frac{de}{dt}$ menghadapi batasan fisik.

1. Strategi Tuning Berdasarkan Mode

Komponen Kendali Kecepatan Kendali Posisi
Proportional
($K_p$)		 Mengatur respon transien awal. Bertindak sebagai "kekakuan pegas".
Integral
($K_i$)		 Sangat Penting. Menghilangkan error akibat gesekan. Seringkali tidak dibutuhkan (gunakan kecil saja), karena plant sudah memiliki integrator (Type 1).
Derivative
($K_d$)		 Jarang digunakan (rentan noise). Sangat Penting. Memberikan redaman (damping) buatan untuk mencegah overshoot.

2. Fenomena Saturasi (Windup & Clipping)

Motor memiliki tegangan kerja maksimum ($V_{max}$).

  • Clipping: Jika PID meminta 24V tapi baterai hanya 12V, sistem menjadi non-linear. Respon akan lebih lambat dari prediksi teori linear.
  • Integrator Windup: Bahaya laten pada kendali dengan term Integral ($K_i$). Saat aktuator jenuh (mentok di $V_{max}$), error tetap ada. Integral akan terus menjumlahkan error tersebut hingga nilainya sangat besar. Akibatnya, saat target tercapai, sistem "lupa mengerem" karena nilai integral masih sangat besar, menyebabkan overshoot ekstrim.
  • Simulasi ini telah dilengkapi algoritma Anti-Windup (Clamping) untuk merepresentasikan controller industri modern.
